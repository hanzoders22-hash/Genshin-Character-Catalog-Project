# Genshin Character Catalog & Text RPG Game

Комплексний навчальний проєкт, що поєднує **каталог персонажів**, **покрокову текстову гру**, **постійну систему збережень** та **графічний інтерфейс**.

##  Опис проєкту

Проєкт складається з таких основних модулів:

### 1. **Каталог персонажів**

* Завантажує дані про персонажів із відкритого API:
  [https://genshin.jmp.blue](https://genshin.jmp.blue)
* Парсить отримані JSON-дані та структурує їх для подальшого використання.
* Завантажує портрети персонажів та кешує їх у локальні файли.
* Відображає список персонажів у графічному інтерфейсі у вигляді карток:

  * ім’я
  * портрет
  * коротка інформація
* Дозволяє створювати користувацьких персонажів та зберігати їх.

### 2. **Текстова RPG гра**

* Дозволяє вибрати персонажа зі списку доступних.
* Має повністю реалізовану математику бою та механіки взаємодії персонажів (описані в дизайн-документі).
* Реалізує покроковий ігровий цикл:

  * виконання дій
  * обробка стану
  * виведення історії кроків
* Підтримує:

  * **save/load** прогресу
  * відновлення гри з останнього збереження
  * завантаження нових персонажів

### 3. **Постійність даних**

* Збереження:

  * користувацьких персонажів
  * стану гри
  * кешованих зображень
* Файлова структура спроєктована так, щоб мінімізувати запити до API.

### 4. **Графічний інтерфейс**

* Компонент каталогу персонажів:

  * прокручуваний список карток
  * портрети та опис
* Компонент текстової гри:

  * текстовий лог кроків
  * кнопки вибору сейвів
  * інтерфейс запуску та продовження гри

### 5. **Командний інтерфейс (CLI)**

Для тестування поза GUI доступна консольна взаємодія:

* перегляд каталогу
* створення нових персонажів
* текстові варіанти управління грою

##  Структура проєкту

```
project/
│── img/                 # Локальний кеш графіки персонажів
│── components/          # Графічні компоненти інтерфейсу
│── pages/               # GUI-сторінки
│── data/                # Збереження та локальні JSON
│── src/                 # Вихідний код бізнес-логіки
│── README.md            # Документація
│── design_document.docx # Дизайн-документ
│── main.py / main.js    # Точка входу
```

##  Технології

* **Python / JavaScript** (залежно від реалізації)
* **JSON API**
* **Local file caching**
* **GUI (Tkinter / PyQt / HTML+JS / інше)**
* **OOP + модульна архітектура**

##  Запуск проєкту

1. Склонуйте репозиторій:

   ```
   git clone https://github.com/your-username/project-name.git
   ```
2. Встановіть залежності:

   ```
   pip install -r requirements.txt
   ```

   або (JS):

   ```
   npm install
   ```
3. Запустіть застосунок:

   ```
   python main.py
   ```

   або (JS):

   ```
   npm start
   ```
